# Lumina móvil

Consulta tus alertas, administra a quién se envían y conversa con Lumina desde tu teléfono.
Para ingresar, usa el código de planta que te entregó tu equipo y tu cuenta de Lumina.

## Android

1. Descarga **Lumina-1.4.0.apk** desde [la versión de Android](https://github.com/optimizo-cl/Lumina-Mobile/releases/tag/v1.4.0).
2. Abre el archivo y sigue los pasos de Android para instalarlo.
3. Abre **Lumina**. Si quieres avisos con la app cerrada, activa **Avisos → Notificaciones en este teléfono**. Usa Chrome actualizado para recibirlos.

## iPhone y iPad

1. Abre [Lumina](https://app.lumina.optimizo.ai/app/) en Safari.
2. Toca **Compartir → Añadir a pantalla de inicio**. Si ves **Abrir como app web**, actívalo y toca **Añadir**.
3. Abre Lumina desde el icono nuevo. Para recibir notificaciones con la app cerrada, instala la app web, usa iOS o iPadOS 16.4 o posterior y actívalas en **Avisos**. [Guía de Apple](https://support.apple.com/guide/iphone/iphea86e5236/ios).

En otros dispositivos, abre [Lumina en el navegador](https://app.lumina.optimizo.ai/app/).
